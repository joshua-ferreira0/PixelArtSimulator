# Pixel Art Simulator

A browser-based pixel art editor built using HTML, CSS, and vanilla JavaScript.

This project explores computer graphics, algorithms, and interactive web development using the HTML5 Canvas API.

## Demo

A short demonstration of the application:
https://github.com/user-attachments/assets/1856509f-139c-42fe-8d71-657f2f6ee35c

## Features

- Pencil, eraser, paint bucket, and colour picker tools
- Adjustable brush sizes and canvas dimensions
- Custom colour palette
- Undo/Redo functionality
- Multiple frame creation and management
- Zoom controls and live preview
- Export artwork as PNG, spritesheets, or JSON

## Running Locally

Clone the repository:

```bash
git clone https://github.com/joshua-ferreira0/PixelArtSimulator.git
```

Open `index.html` in your browser.
